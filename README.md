SmartFactoryBot
Proyecto desarrollado para la materia: Desarrollo de aplicaciones con inteligencia artificial.

Descripción
SmartFactoryBot es un chatbot de soporte para entornos de manufactura que utiliza técnicas de Procesamiento de Lenguaje Natural (NLP) y Machine Learning para identificar automáticamente la intención de las consultas realizadas por los usuarios.

Tecnologías
Python
NLTK
Scikit-Learn
TF-IDF
Support Vector Machine (SVM)
Funcionalidades
Clasificación de intenciones
Soporte ITAC
Soporte MES
Soporte Impresoras
Soporte Scanners
Escalación de incidencias
Registro de conversaciones
Generación automática de métricas
Mejor resultado obtenido
Accuracy: 80%
